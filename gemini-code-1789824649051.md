# Product Requirements Document (PRD)
## Website Company Profile, Multi-Page Catalog & Portfolio Gallery

---

### 1. Ringkasan Proyek & Tujuan
* **Nama Proyek:** Wintom Curtain Company Profile & Dynamic Catalog (MVP)
* **Tujuan Utama:**
  * Menampilkan profil bisnis gorden arsitektural/premium, standar layanan survei, dan garansi instalasi.
  * Menyediakan katalog produk interaktif (daftar produk & detail produk) serta arsip galeri portofolio visual.
  * Mengonversi calon pembeli langsung ke WhatsApp dengan pesan dinamis terformat otomatis sesuai produk yang dilihat.
  * Menyediakan panel admin mandiri di `/admin` untuk mengelola katalog produk (termasuk multi-foto detail) dan galeri portofolio.
* **Prinsip Arsitektur:** PHP Native 8.x + SQLite, Tailwind CSS via CDN, zero-build-step, hemat token AI saat *vibe coding*, dan kompatibel langsung dengan shared hosting cPanel.

---

### 2. Sumber Desain & Protokol Slicing (Figma via MCP)

Proyek ini menggunakan desain presisi langsung dari Figma yang diekstrak menggunakan **Figma MCP**.

#### A. Batasan Tooling & Larangan Build Step (Strict Rule)
* **DILARANG** membuat *scaffolding* atau proyek berbasis **Vite, Node.js, npm, Webpack, Parcel, React, maupun framework frontend JS lainnya**.
* **DILARANG** menghasilkan output file berupa komponen JSX/TSX atau folder `dist/`.
* Output dari Figma MCP wajib berupa **Pure Semantic HTML5** dengan styling utility class **Tailwind CSS**.
* Seluruh styling memanfaatkan **Tailwind CSS via CDN** (`<script src="https://cdn.tailwindcss.com"></script>`), langsung ditempelkan ke dalam file template `.php`.
* Semua icon diekstrak sebagai **inline SVG**, dan aset gambar statis disimpan langsung di folder `/assets/images/`.

#### B. Template Prompt Pengendali AI Agent / MCP
Gunakan instruksi baku berikut setiap kali meminta AI melakukan slicing dari Figma:

> *"Slicing frame Figma berikut: `[MASUKKAN_URL_FIGMA_DI_SINI]`. Jangan buat proyek Vite, Node.js, atau React. Hasilkan kode berupa potongan HTML5 semantik murni dengan utility class Tailwind CSS yang presisi sesuai token Figma (warna, font family, rasio gambar, padding, dan gap). Kode harus siap langsung ditempel ke dalam file template PHP (`.php`) tanpa build step apa pun."*

### 3. Arsitektur Halaman Publik (5 Halaman Utama)

#### A. Homepage (`index.php`)
* **Hero Section:** Value proposition, tagline kemewahan arsitektural, dan tombol CTA konsultasi.
* **Keunggulan Layanan:** Informasi survei gratis Jabodetabek, custom dimensi ruangan, dan swatch kain fisik langsung ke lokasi.
* **Koleksi Unggulan:** Cuplikan beberapa produk terbaik dari database.
* **Tiga Langkah Pemesanan:** Alur kerja (Pilih Koleksi & Konsultasi, Jadwalkan Survei Gratis, Instalasi Presisi & Garansi).
* **Footer:** Navigasi, jam operasional, tautan media sosial, kontak, dan alamat showroom.

#### B. Halaman Katalog Produk (`products.php`)
* **Header Koleksi:** Judul seksi kurasi produk dan ringkasan layanan.
* **Filter Kategori Dinamis:** Tab filter kategori (Semua Produk, Curtain, Vitrase & Sheer, Roller Blind, Motorized Smart System, Wood & Bamboo Blind).
* **Grid Kartu Produk:**
  * Foto cover produk (aspect-ratio konsisten, misal `aspect-[3/4]`).
  * Label badge jenis kain (contoh: *DIMOUT, SHEER, MOTORIZED, ORGANIC WOOD*).
  * Nama seri gorden.
  * Badge diskon persentase dan harga coret.
  * Harga per meter bahan.
  * Tombol aksi ganda: **"Lihat Detail"** (link ke `product-detail.php?slug=...`) dan **"Via WhatsApp"**.

#### C. Halaman Detail Produk (`product-detail.php`)
* **Galeri Multi-Foto:** Foto utama resolusi tinggi disertai baris thumbnail foto detail tekstur material dari tabel `product_images`.
* **Informasi Produk Lengkap:**
  * Judul seri produk dan kode referensi arsitektural (contoh: *REF: BEL-102*).
  * Paragraf deskripsi material dan karakteristik kain.
  * Estimasi harga per meter bahan (termasuk jahit).
  * Pilihan variasi interaktif (opsi warna, pilihan dimensi, dan model jahitan seperti *Ripple Fold / S-Fold Wave*).
* **CTA Utama:** Tombol **"Konsultasi & Cek Estimasi via WhatsApp"** yang otomatis menyusun pesan dinamis.
* **Protokol Pemesanan:** 4 tahap (Konsultasi Awal, Survei & Swatch, Penjahitan Atelier, Pemasangan Rapi).
* **Rekomendasi Terkait:** Grid produk tekstil alternatif/pelengkap.

#### D. Halaman Galeri Portofolio (`gallery.php`)
* **Header Arsip Visual:** Judul galeri dan kurasi hasil pengerjaan tirai.
* **Filter Kategori Proyek:** Tab filter tipe bangunan/ruangan (Semua Proyek, Living Room, Penthouse Sanctuary, Dining & Atelier, Office & Commercial, Hotel & Private Villa).
* **Grid Portofolio:** Tampilan foto dokumentasi pemasangan gorden dari tabel `galleries`.
* **Seksi Reservasi:** Banner ajakan survei dan pengukuran ke lokasi.

#### E. Halaman Tentang Kami & Kontak (`about.php`)
* **Cerita Brand:** Profil atelier gorden, standar penjahitan, dan kontrol kualitas kain.
* **Layanan Lengkap:** Penjelasan survei onsite hingga layanan purnajual.
* **Informasi Kontak & Lokasi:** Peta/alamat showroom, nomor telepon, dan tautan chat langsung.

### 4. Ruang Lingkup Admin Panel (`/admin`)

Halaman admin dibuat sederhana untuk mengelola dua modul dinamis:

1. **Modul Produk (`admin/products.php`):**
   * Tambah produk: nama, slug, kategori, badge, kode referensi, harga asli, harga diskon, satuan harga, deskripsi, spesifikasi, dan upload foto cover.
   * Multi-image upload untuk thumbnail galeri di halaman detail (`product_images`).
   * Edit data produk yang sudah ada.
   * Hapus produk (otomatis menghapus rekaman database dan file gambar fisik di `/uploads/`).
2. **Modul Galeri (`admin/gallery.php`):**
   * Upload foto dokumentasi portofolio baru.
   * Input judul proyek dan kategori ruangan.
   * Hapus foto portofolio beserta file fisiknya dari server.
3. **Autentikasi & Keamanan:**
   * Login berbasis username dan hash password (`password_hash()`).
   * Proteksi akses admin dengan PHP Native Session (`session_start()`).

### 5. Skema Database SQLite (`database/curtains.sqlite`)

```sql
-- Tabel Admin Panel
CREATE TABLE IF NOT EXISTS admins (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    username TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL
);

-- Tabel Produk Utama
CREATE TABLE IF NOT EXISTS products (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    slug TEXT UNIQUE NOT NULL,
    name TEXT NOT NULL,
    category TEXT NOT NULL,
    badge TEXT,
    ref_code TEXT,
    price INTEGER NOT NULL,
    original_price INTEGER,
    price_unit TEXT DEFAULT '/ meter',
    description TEXT,
    features TEXT,
    options_json TEXT,
    cover_image TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- Tabel Galeri Multi-Foto Khusus Detail Produk
CREATE TABLE IF NOT EXISTS product_images (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    product_id INTEGER NOT NULL,
    image_url TEXT NOT NULL,
    sort_order INTEGER DEFAULT 0,
    FOREIGN KEY (product_id) REFERENCES products(id) ON DELETE CASCADE
);

-- Tabel Portofolio Galeri Pemasangan
CREATE TABLE IF NOT EXISTS galleries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT NOT NULL,
    category TEXT NOT NULL,
    image_url TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
